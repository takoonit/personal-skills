# Expressive design

Use with the shared foundations. Make boldness systematic enough to be recognised and used. Expression should reflect the brand's specific voice rather than a collection of loud effects.

## Character and fit

Useful for cultural organisations, entertainment, creative products and challenger brands with a clear point of view. Fit depends on audience context and identity, not a rule that younger users prefer maximalism. Strong expression can exclude as well as attract; do not claim popularity or a premium impression without evidence.

Choose the project's grammar: for example, neo-brutalist blocks and hard edges, composed maximalist layering, or a graphic poster language. These are variants of the primary Expressive style, not permission to mix unrelated systems. State what is allowed to be loud and what anchors comprehension.

## Composition, colour and shape rules

- Establish a dominant element and an ordered secondary tier. Density is permitted; equal emphasis everywhere is not. Preserve a quiet region or stable structure around navigation, instructions and critical decisions.
- For a neo-brutalist variant, define block geometry, border weight, hard-shadow offset and state changes as a small reusable grammar. Do not add soft glass and diffuse shadows to arbitrary cards.
- For a maximalist variant, define a layer order, recurring motif family and colour relationships. Every added layer should reinforce story, hierarchy or rhythm. Do not treat empty space as a defect to fill.
- Use a purposeful palette with semantic foreground/background pairings. Saturated colours can sit together if text/action boundaries remain clear. Record which colour combinations are allowed for reading and which are artwork only.
- Choose display type for the brand's voice and keep dependable supporting type. Oversized headlines, condensed faces and distorted lettering belong in defined roles. Do not use them for dense instructions, prices or long form values.
- Repeat selected shape, border, symbol and image treatments across sections. A surprise should change composition or content within a recognisable grammar, not reset the entire system each time.
- Artwork may crop or overlap; essential words, navigation and controls may not disappear behind it. Decorative stickers, badges and symbols need a visual meaning or should be reduced.

## All six techniques

| Technique | Concrete application |
|---|---|
| Anchor typography | Choose a strong display role and a calm support role, with script-aware fallbacks. Define where oversized, condensed or irregular type is allowed and its readable mobile counterpart. |
| Star of the show | Lead with a meaningful statement, artwork or primary interaction. Identify the dominant contrast/scale relationship so other loud elements do not compete equally. |
| Visual rhyming | Repeat a chosen symbol, border, crop or colour relationship in at least two named applications. Fix its meaning and geometry rather than adding a new graphic gimmick to each section. |
| Subtle depth | For a hard-edged grammar, use controlled offset shadows or cut-out layers; for layered collage, define overlap and texture roles. Keep depth subordinate to the star even when the overall style is loud. |
| Text opacity and emphasis | Use semantic text levels on approved saturated surfaces. Supporting emphasis may use a quieter opaque colour rather than low alpha. Essential labels must stay readable against every permitted pairing. |
| Design variations | Compare a poster-like composition with an asymmetric modular arrangement using the same content and chosen grammar. Judge focal clarity and task completion alongside character. |

## Components and interaction

Keep conventional semantics beneath the expressive appearance: links navigate, buttons act, inputs are labelled. Custom cursors cannot be the only pointer cue. A draggable visual interaction needs an alternative where applicable; playful controls must not obscure their outcome.

Define focus as an unmistakable boundary that differs from decorative borders. A hard shadow may compress on press, but the hit target should remain stable. Distinguish selected/pressed/disabled states using more than a tiny positional change. Keep error and confirmation language clear even if the brand voice is playful.

A critical action or checkout can retain type, colour and border identity while reducing background density. Do not introduce a second minimal style; apply the same grammar with less competing artwork. Preserve hierarchy for prices, terms and recovery paths.

## Mobile, motion and delivery

Reflow poster type and stacked blocks to the viewport; do not accept page-wide overflow as part of the aesthetic. Allow artwork to crop only when its meaning survives. Keep dense compositions in a logical document order and verify focus visibility around overlaps.

Use motion to express feedback or a defined focal event. Avoid flashing, multiple endless marquees and constant shaking. Honour pause/reduced-motion needs; the static layout must retain the brand's character. Optimise large artwork, texture and fonts so boldness does not require an expensive runtime.

## Failure patterns and review

| Reject | Verify instead |
|---|---|
| Every element shouts with the same contrast and scale | A dominant focal element and predictable action hierarchy remain |
| Neo-brutalist, glass and soft-card systems mix arbitrarily | One documented shape/depth grammar explains the components |
| Brand personality overrides control meaning | First-time users can identify actions, state and recovery |
| The mobile page is a cropped desktop poster | Content reflows and every essential control remains usable |

Possible project rules: use the named hard-border/shadow system for controls; restrict stickers to content decoration; preserve a calm form region; allow only the tested foreground/background pairs. Tie the chosen rules to actual tokens and components.
