# Register examples

Use these to calibrate tone. Adapt facts and length to the user's request.

## Working chat

Input: The button saves a draft but is labeled Publish.

Draft: "This button saves a draft, so 'Publish' gives the wrong expectation. Please change it to 'Save draft'."

State the behavior and correction without speculating about anyone's competence.

## Thai professional request

Input: Ask a colleague to confirm one of two previously proposed times. Neither is booked.

Draft: "รบกวนยืนยันเวลาที่สะดวกจากสองช่วงที่ส่งไปให้หน่อยครับ แล้วผมจะส่งนัดหมายให้หลังจากยืนยันเวลาแล้ว"

Do not imply the meeting is already booked. Add a greeting or thanks only when the relationship and medium call for it.

## English scope clarification

Input: The user agrees to review a proposal, but has not agreed to implement it.

Draft: "I can review the proposal and share feedback. Implementation would need a separate agreement on scope and timing."

Politeness must not imply acceptance of additional work.

## Editing check

Compare actor, request, commitments, conditions, dates, and uncertainty with the supplied facts. Preserve useful specificity; remove repeated explanation.
