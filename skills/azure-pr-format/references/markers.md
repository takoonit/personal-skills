# Legacy colored-format marker vocabulary

Use this only for an explicitly selected older colored format or detailed record. The default team PR has What Happened, Insight and Proof of Works; see [the team convention](team-writing.md).

| Marker | Meaning | ASCII for commits | Required treatment |
|---|---|---|---|
| 🔵 | Event | o | A dated occurrence when known |
| 📝 | Note | - | Fact; distinguish inference |
| ✅ | Done / confirmed | x | Finished work or evidenced confirmation |
| ❌ | Dropped / rejected | ~ | Always include reason |
| ➡️ | Moved | > | Link actual follow-up destination |
| ⏳ | Waiting / scheduled | < | State dependency or reason |
| ⬜ | Open | . | Still to do in this PR |
| 💡 | Insight | ! | Finding that changed the decision |
| ❓ | Question | ? | Specific unresolved reviewer question |
| ⚠️ | Risk | !! | Failure possibility and consequence |
| ⭐ | Priority | * | Prefix an important item |

Test statuses are ✅ Pass, ❌ Fail, ⏳ Not run — reason. Here ❌ is a failed result, not a dropped option; context and words disambiguate it. Risk values are 🟢 Low, 🟡 Medium, 🔴 High, always with word and justification. Before and After retain those written labels.

Section bands: 📌 TL;DR; 🟦 Why; 🟪 Thinking; 🟩 Changes; 🎨 Diagram (record); 🟨 Test; 🟥 Rollback; ⬜ Note to future you (record). Shape and text carry meaning without color. Emoji appearance varies across clients; do not claim universal visual accessibility from color alone.
