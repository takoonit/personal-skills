Strategic Gate
Choose what to work on. If you need a plan for the chosen work, ask Shape System Work.
Shape System Work
Plan what to include and how to check that it works. Ask Ship Sound Code to build it when you agree with the plan.
Ship Sound Code
Build and test the agreed change. Ask Lundy for a separate check when the existing checks do not prove an important result.
Lundy
Compare the requirements with the code and test results. Say what passed, what is uncertain, and what to check next.

Example requests.

These examples show how to choose, plan, build, and check an admin-only invoice export. Open the request you need.

Strategic Gate · choose
$strategic-gate
I have five dev-days. Two customers need CSV export; an onboarding rewrite may help signups, but evidence is weak. What deserves this week?
Shape System Work · plan
$shape-system-work
We have decided to add admin-only invoice export. Keep our login system and database. Plan the first version: what to include, what to leave out, who can use it, and how to check that it works. Planning only.
Ship Sound Code · build
$ship-sound-code
Implement the accepted admin-only CSV export in this repo. Preserve existing permissions and export only invoices the admin can access. Verify rejection for non-admins. Don't commit.
Lundy · check
$lundy
The export is marked complete. Check whether only admins can use it, whether it includes only invoices they can access, and whether the CSV is valid. Review the code and test results separately; don't edit.
